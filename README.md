# recursive-fact-hash

Факторизация числа `N = p × q` перебором по разрядам справа налево с использованием дерева вариантов, хэш-структур и рекурсии.

## Алгоритм

1. **Решето Эратосфена** — генерация всех m-значных простых чисел.
2. **Карта расширения** (`build_extend_map`) — для каждого хвоста `(t, tail)` хранятся цифры, которые могут стоять слева от него в m-значном простом.
3. **DFS с отсечением** — последние цифры (единицы) множителей могут быть только из {1,3,7,9}. На каждом шаге перебираются возможные следующие цифры слева, и ветка отсекается, если произведение не совпадает с `N` по модулю `10^(t+1)`.

## Использование

```python
from factorize_by_digits import factorize_by_digits

# Двузначные множители для 143
print(factorize_by_digits(143, 2))  # [(11, 13)]
```
